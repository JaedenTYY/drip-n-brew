# RELEASE NOTES - June 21, 2026

## The "Free Drink Promo" Update

This release completely reworks the promo code logic to introduce "1 Free Drink" capabilities alongside the existing percentage discounts.

### ✨ New Features
- **1 Free Drink Promo Codes:** You can now create promo codes that specifically grant 1 Free Drink instead of an entire bill percentage discount.
- **Dynamic Drink Selection:** When a customer applies a Free Drink promo code on the storefront, an interactive UI prompts them to select exactly which drink in their cart they wish to claim for free.
- **Upgraded Promo Manager:** The POS Promo Manager has been updated to easily toggle between Percentage (%) and 1 Free Drink discount types.

### 🛠️ UX Improvements
- **Checkout Guardrails:** Added strict validation ensuring customers cannot proceed to checkout without explicitly selecting their free drink when a free drink code is applied.

# RELEASE NOTES - June 7, 2026

## The "Custom Layout" Update

This release introduces the much-anticipated Dynamic Menu Layout Engine, allowing for granular control over how products and categories are presented across the Drip-n-Brew ecosystem.

### ✨ New Features
- **Dynamic Menu Layout Engine:** A full-featured administrative suite for real-time POS organization.
    - **Drag-and-Drop Reordering:** Effortlessly reorganize categories and individual drinks via a new intuitive visual interface in the POS settings.
    - **Categorization of Drinks:** Improved logic for grouping products, ensuring a cleaner and more navigable menu for baristas.
    - **Bulk Layout Saving:** Optimized state management allows for saving complex layout changes in a single, high-performance transaction.

### 🛠️ UX Improvements
- **Tighter Storefront Spacing:** Refined the storefront grid layout to reduce whitespace, allowing more products to be visible on the screen simultaneously without sacrificing readability.
